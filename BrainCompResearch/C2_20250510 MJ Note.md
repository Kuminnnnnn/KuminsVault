**-> different types of memory**
	1. **Episodic memory**
		1. about episode - went to a bar, a party, a zoo
		2. **Instantaneous**: no need to try to learn
		3. Brain can use episodic memory to train itself(refine knowledges) - like dream
	2. **Procedural memory**
		1. skills - riding bike...
		2. Requires **repetition and practicing** to slowly improve
		3. Won't be easy faded - **slow to degrade**
	3. **Declarative memory**
		1. Facts - capital of China
		2. Speed: it depends

->**Memories move around, change format**
	Episodic memory may change to declarative memory
		telling a specific episodic memory to many people for many times, the episodic will become declarative memory like telling a story
