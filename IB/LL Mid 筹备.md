# 封锁
## 封锁含义
- **表层：** 战时日军搜查、交通封锁。
- **中层：** 电车的封闭空间 → 都市社会的缩影。
- **深层：** 人的精神被“封锁”——个体孤立、压抑、被困在身份与欲望之间。
- **结构呼应：** 封锁→解除→常态恢复→一切如梦。象征都市人短暂的“出神”与最终归于麻木。

## 手法
1. **环形结构**
	1. 开放 - 封锁 - 开放
	2. 正常 - 不正常 - 正常
2. **群像**
	1. **慌乱、混乱、无措** -> 动物本能
		1. *“有报的看报，没有报的看发票，看章程，看名片”*
		2. *“任何印刷物都没有的人，就看街上的市招”*
		3. *“他们不能不填满这可怕的空虚——不然，他们的脑子也许就会活动起来。思想是痛苦的一件事”*
	2. **对峙** -> 冷漠无情
		1. *“我就看不惯现在兴的这种立体派，印象派！”*
		2. *“中国画的影响，现在西洋的画也兴题字了，倒真是’东风西渐‘”*
	3. **静** -> 日常生活打断促使个人重新思考主体性 -> 集体性焦虑恐慌
3. **”真“**——所能触动吴翠远的
	1. **大胆批判**的学生作业
		1. 一个男生作的，充满正义感的怒吼的，不和文法的
		2. *”若在平时，批了也就批了，可是今天她有太多的考虑的时间，她不由得要质问自己，为什么她给了他这么好的分数“*
		3. 因为真
	2. **脚**
		1. *”小小的老虎头红鞋抱着柔软而坚硬的脚····这至少是真的“*
		2. 矛盾的语言表达 -> 柔软是触感、坚硬是真实
	3. 分享”**境地**“ -> “同情”、“同病相怜” -> **真诚**打动了wcy
		1. *”你不知道——我家里——咳，别提了！“*
		2. *”我太太——一点都不同情我。“*
		3. *”你——你不知道他是怎么样的一个女人“*
		4. 破折号 -> **犹豫** -> **勇气、挑战**
		5. *”近视眼的人当众摘下眼镜子，翠远觉得有点秽亵，仿佛当众脱衣服似的“* -> 袒露心胸、**真诚**
4. **吴翠远人物形象**
	1. **双重女性困境**
		1. 错位的家庭责任
			1. *”然而家长渐渐对她失掉了兴趣，宁愿她当初在书本上马虎一点，匀出点时间来找一个有钱的女婿*
		2. 职业身份压力
			1. *“吴翠远在学校里老是觉得谁都看不起她”*
			2. *“申大越来越糟糕了！一天不如一天！用中国人教英文，照说，已经不是应当，何况是没有出过洋的中国人！”*
	2. **外在**
		1. **老气** -> 社会规训 
			1. *“教会派的少奶奶，但是还没有结婚”*
			2. *”头发梳成千篇一律的式样，唯恐唤起公众的注意“*
			3. *”模棱两可的美“*
			4. *”连他自己的母亲也形容不出她是长脸还是圆脸“*
		2. **颜色**
			1. *“深蓝与白，很有点讣闻的氛围”* - **比喻**
			2. **庄重、克制、社会规训**
	3. **心理描写**
		1. 自我审视
			1. *”她是一个好女儿，好学生“*
			2. *”洗澡听贝多芬、瓦格涅的交响乐，听不懂也要听“*
			3. **好、雅、有学识、家庭氛围、规训**
5. **吕宗桢内心状态**
	1. **压力**：牢骚
		1. *“她一点也不为他着想”*：西装男拎着包子满街跑，不体面
	2. **放松舒服享受**：主题身份“自我”“人性”/ **男性主导**
		1. *“她一脸红，让他看到了，他显然是很愉快。”*
		2.  “*使一个女人脸红，使她微笑，使她背过脸去，使她掉过头来* ”
			1. **四个使动** -> **跳切** -> **强调**
	3. **回到现实**，从非常态到常态，开始**痛苦**；**现实与理想**的冲突与矛盾
		1. *“我打算重新结婚*” -> **逃离**、**”叛逆“**
		2. **勇气** -> **挑战**
		3. 然而：**清醒、懦弱** -> 社会规训的强大
			1. *“我根本不该起这种念头······我年纪太大了。我已经三十五岁了”*
		4. **矛盾痛苦** -> 同情
		5. *“遥遥坐在他原来的位子上”* -> **自私**、**虚伪**
			1. 一切都是wcy**自我感动**
			2. lzz重新化为都市生活中的没有灵魂的**行尸走肉**
6. **比喻、意向、象征**
	1. *“**生命**像《圣经》”*，被不同的语言翻译过后没了**意义**
		1. **表层意思**：圣经本来有个最初的、最接近“真理/原始启示”的版本，但被翻译了好多道，最后读到我们手里时，味道已经变了。
		2. **对应到“生命”**：人的生命也是这样，被一层一层“翻译”——
		    - 原本的欲望/本能/真实感受
		    - → 被家庭期待“翻译”一层
		    - → 被学校/职业规范“翻译”一层
		    - → 被当时上海的“好人文化、西式教养”再翻一层
		    - → 到了她脑子里，最后还要转成“上海话”才能消化
		    - 结果：**越到后面越不像原来的生命了**。
	2. 电车像“**曲蟮**”
		1. 恶心
		2. 没完没了
		3. 生活
	3. 从**没有款式的牙膏**变成**白描牡丹花**再到**男性嘴里呵出来的一口气**
		1. 黑色幽默、贬低 -> 普通，符合社会规矩的
		2. 普通却独带一丝清秀的
		3. 距离拉近，然而成为了男人的附庸，没有实体
