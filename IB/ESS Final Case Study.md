# 8.1

| **Category**                     | **Case**                       | **Key Features / Evidence**                                                                                                           |
| -------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| **DTM Stage 1: High stationary** | Amazon Yanomami tribe          | High BR & DR, no modern healthcare, unstable food, low life expectancy.                                                               |
|                                  | Traditional Inuit (historical) | Harsh climate, isolated, high infant mortality.                                                                                       |
| **DTM Stage 2: Early expanding** | Sudan                          | High BR, falling DR due to aid/medicine, youthful pyramid.                                                                            |
|                                  | Afghanistan                    | High BR (Islamic pro-natalist, son preference, early marriage, *Blessing of Allah*), DR dropped with aid, conflict raises DR locally. |
| **DTM Stage 3: Late expanding**  | Brazil                         | Urbanization, female education, contraception, DR low, TFR declining.                                                                 |
|                                  | Mexico                         | BR from 6.7 → ~2.1, >80% urban, improved healthcare.                                                                                  |
| **DTM Stage 4: Low stationary**  | UK                             | Low BR (~1.7), low DR, stable pop., immigration maintains growth.                                                                     |
|                                  | USA                            | BR low (~1.6–1.7), immigration important, high life expectancy.                                                                       |
| **DTM Stage 5: Declining**       | Japan                          | TFR ~1.3, 27% aged 65+, shrinking labor force.                                                                                        |
|                                  | Germany                        | TFR ~1.5, natural decrease, aging, relies on immigration.                                                                             |
| **Cultural factors**             | India                          | Son preference, large families = social status, rural labor.                                                                          |
|                                  | China (historical)             | Male preference → sex-selective abortions.                                                                                            |
| **Historical factors**           | Europe (Industrial Revolution) | Mechanization reduced child labor need → lower BR.                                                                                    |
|                                  | Rwanda (1994 genocide)         | Conflict raised DR, male deaths → population imbalance.                                                                               |
|                                  | Black Death (14th c. Europe)   | Epidemic → massive DR, population collapse.                                                                                           |
| **Religious factors**            | Philippines                    | Catholic ban on contraception → high BR.                                                                                              |
|                                  | Iran (1979–1989)               | Pro-natalist after Islamic Revolution, later family planning (1990s).                                                                 |
| **Social factors**               | South Korea                    | Female education + urbanization → lowest TFR (~0.7).                                                                                  |
|                                  | Bangladesh                     | Female literacy + contraception → BR decline.                                                                                         |
| **Political factors**            | China                          | _One-Child Policy_ (anti-natalist) → fertility fell <2, aging pop.                                                                    |
|                                  | France                         | _Code de la Famille_ (pro-natalist) → maternity leave, childcare, fertility support.                                                  |
|                                  | Singapore                      | Shift from _Stop at Two_ (anti-) to _Have Three or More_ (pro-). Fertility still ~1.1.                                                |
| **Economic factors**             | Nigeria                        | Poor economy, children = labor & old-age security → high BR.                                                                          |
|                                  | Japan                          | High cost of living/education → very low BR.                                                                                          |
| **Technological factors**        | Sub-Saharan Africa             | Limited contraception + weak healthcare → high BR & DR.                                                                               |
|                                  | Sweden                         | Advanced medical system, low DR, long life expectancy.                                                                                |
|                                  | India                          | Family planning & contraceptives → TFR decline.                                                                                       |
| **Population policies (extra)**  | India (1970s)                  | Sterilization campaigns (anti-natalist) → controversial, human rights concerns.                                                       |
|                                  | Iran (1990s FP program)        | Free contraception, marriage courses → TFR fell 6.5 → 2, later reversed.                                                              |
|                                  | Nigeria (1988, 2004 policy)    | Family planning, maternal healthcare, mixed success (TFR still ~5.1).                                                                 |
